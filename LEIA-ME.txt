PROTEÇÃO DEFINITIVA — ROTAS DO SERVIDOR

Esta versão NÃO depende do middleware para bloquear as páginas.
O vercel.json envia todas as rotas internas para api/protected-page.js.
A função verifica o cookie assinado pcu_session antes de entregar o HTML.

SEM SESSÃO:
/consulta, /consulta.html, /mentoria, /perfil e demais áreas internas
retornam 302 para /?acesso=restrito.

COM SESSÃO VÁLIDA:
a função entrega o arquivo HTML normalmente.

ARQUIVOS OBRIGATÓRIOS NA RAIZ:
- vercel.json
- package.json
- middleware.js (neutraliza a versão anterior)
- login.html
- todos os HTML internos
- pasta api com session.js e protected-page.js

IMPORTANTE:
1. Substitua o vercel.json antigo.
2. Substitua o middleware.js antigo pelo deste pacote.
3. Envie api/protected-page.js e api/session.js.
4. Faça um novo deploy de PRODUÇÃO.
5. Teste em janela anônima, pois o navegador normal pode manter uma sessão válida por 12 horas.
